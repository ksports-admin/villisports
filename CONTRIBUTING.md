## Contributing

We're looking for help with:
- UI/UX designs (Figma links, images, etc.)
- File/folder structure for frontend
- Code improvements, suggestions

### How to Submit UI/UX Designs
1. Fork this repo
2. Create a folder under `/designs` (e.g. `/designs/johndoe`)
3. Upload images or share Figma/AdobeXD/Canva links
4. Create a Pull Request

Or just open an issue with your design attached.

### How to Suggest File Structure
1. Fork the repo
2. Create a folder `/structure-proposals/yourname`
3. Include a proposed folder tree or architecture diagram
4. Open a PR with a short explanation
